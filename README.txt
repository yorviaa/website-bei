WEBSITE DOKUMENTASI KUNJUNGAN INDUSTRI — IDX

CARA MENJALANKAN
1. Ekstrak folder website-bei.
2. Masukkan 10 foto dokumentasi asli ke folder assets/images.
3. Beri nama foto secara berurutan: foto1.jpg, foto2.jpg, ... foto10.jpg.
4. Masukkan video vlog berdurasi sekitar 90 detik ke assets/video dengan nama vlog-idx.mp4.
5. Klik dua kali index.html untuk membuka website di browser.

CATATAN
- Website dibuat dengan HTML, CSS, dan JavaScript tanpa instalasi tambahan.
- Koneksi internet diperlukan untuk memuat font Google Fonts; website tetap dapat dibuka tanpa internet dengan font pengganti.
- Ganti teks rangkaian kegiatan, kesimpulan, dan refleksi agar sesuai dengan kegiatan kunjungan yang benar-benar dilakukan.
- Pastikan foto dan video yang digunakan adalah dokumentasi milik sendiri dan sudah mendapat izin jika menampilkan orang lain.
